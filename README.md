# Personal Portfolio – Hamza Azeem

A modern, feature‑rich portfolio website built with React, Vite, and Tailwind CSS.

## Features
- **3D interactive hero scene** with a desk and floating code keywords that react to mouse movement.
- **Voice‑powered project search** (Web Speech API).
- **Live GitHub stats** on project cards (stars, forks, last update).
- **Interactive terminal** with custom commands and a hidden snake game.
- **VS Code‑style command palette** (`Ctrl+K`) for quick navigation and actions.
- **Easter eggs** – Konami code (↑↑↓↓←→←→BA) triggers confetti, typing "disco" enables disco mode.
- **Real contact form** (Formspree integration).
- **Multi‑select technology tag cloud** for filtering projects.
- **Grid/List view toggle**, sorting, and URL‑persisted filters.
- **Dark/Light mode** with system preference detection.
- **Smooth page transitions and scroll animations** (Framer Motion).
- **Dynamic stats** that count actual projects and unique technologies.
- **Fully responsive** and accessible (ARIA labels, keyboard navigation, focus styles).
- **SEO optimised** with Open Graph tags and meta descriptions.

## Sections
- **Home** – 3D hero, about, education timeline, services, tech marquee, featured carousel, stats, skills, live GitHub repos, interactive terminal.
- **Projects** – search, voice search, category/tech filtering, sorting, grid/list view, GitHub stats on cards.
- **Contact** – contact info, social links, resume download, interactive map, Formspree contact form.

## Technologies
- React 18 (Hooks, Context, lazy loading)
- React Router v6
- Tailwind CSS (custom theme, glassmorphism)
- Framer Motion
- Three.js / React Three Fiber (3D scene)
- React Icons
- React Helmet Async (SEO)
- Formspree (contact form)
- Canvas Confetti (Easter egg)
- Web Speech API (voice search)
- Vite (build tool)
- Vercel (deployment)
